# Pattern Recognition

A collection of lecture slides and study materials covering core topics in Pattern Recognition and Machine Learning.

## Contents

| File | Topic |
|------|-------|
| `12-Clustering.pdf` | Clustering algorithms and techniques |
| `12-KNN.pdf` | K-Nearest Neighbors (KNN) classification |
| `12.9-Expectation Maximization.pdf` | Expectation Maximization algorithm |
| `13-EM-GMM.pdf` | EM algorithm applied to Gaussian Mixture Models |
| `13-Principal Component Analysis.pdf` | Principal Component Analysis (PCA) |
| `14-EM-missing-data.pdf` | EM algorithm for handling missing data |
| `14-LDA.pdf` | Linear Discriminant Analysis (LDA) |
| `17-NLP.pdf` | Natural Language Processing fundamentals |
| `23-SVD.pdf` | Singular Value Decomposition (SVD) |
| `25-HMM.pdf` | Hidden Markov Models (HMM) |
| `26-dynamical system-kalman filtering.pdf` | Dynamical Systems and Kalman Filtering |
| `27-Algorithm-Independant Machine Learning.pdf` | Algorithm-Independent Machine Learning |

## Topics Covered

- **Unsupervised Learning**: Clustering, PCA, SVD, EM algorithm, GMM
- **Supervised Learning**: KNN, LDA
- **Probabilistic Models**: Hidden Markov Models, Kalman Filtering, Expectation Maximization
- **Natural Language Processing**: NLP fundamentals
- **Dimensionality Reduction**: PCA, LDA, SVD
- **Missing Data Handling**: EM with missing data
